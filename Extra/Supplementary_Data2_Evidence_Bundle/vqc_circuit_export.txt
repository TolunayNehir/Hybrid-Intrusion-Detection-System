VQC (re-uploading comparator) circuit export
============================================================

n_qubits = 8
n_layers = 4
n_trainable_params = 64 (Ry+Rz per qubit per layer, NO classical head)
readout_qubit = 0 (single-qubit P(|1>) marginal IS the attack probability -- no sigmoid, no linear layer, no classical post-processing)

Per-layer structure (repeated for each of the 4 layers):
  1. Data re-upload: Ry(x_i); Rz(x_i) for i in 0..7  <- SAME input features re-encoded every layer
  2. Brick-wall entangler: CNOT(0,1),(2,3),(4,5),(6,7) on even layers; CNOT(1,2),(3,4),(5,6),(7,0) on odd layers
  3. Trainable rotation: Ry(theta); Rz(theta) for i in 0..7

Decision rule: p_VQC = P(qubit_0 = 1) from the exact statevector, thresholded at the D_val-tuned tau.
This is the full and only decision path -- there is no Fisher-feature linear head anywhere in this comparator,
unlike the deployed QuantumAI agent (see Eq. p_deploy in the main manuscript).
